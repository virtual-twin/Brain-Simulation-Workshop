# Demo videos — one cinematic pipeline

All workshop demo screencasts share **one visual language** — a red-circle
cursor that follows the mouse, a narration caption banner, red-square
highlights, and slow deliberate moves — so they look like one series regardless
of which app they record.

## The shared toolkit

| File | Role |
|------|------|
| `code/cinematic.js` | The cinematic primitives (cursor / caption / highlight / click) for the **standalone** node recorders in this repo. |
| `tvbo-platform/tests/e2e/helpers/cinematic.ts` | The **same** primitives for the platform's `@playwright/test` screencasts. |

`cinematic.js` is the CommonJS sibling of `cinematic.ts` — keep the style
constants in sync (cursor `24px` / `#ff2b2b`, the caption banner, the highlight
box). Two runtimes (`@playwright/test` vs raw `playwright`), one look.

## The generators

| Video | Generated by | Records |
|-------|--------------|---------|
| `tvbo-experiment-builder-workflow.mp4` | `tvbo-platform/tests/e2e/specs/demo-workflow.spec.ts` | Odoo platform: KG → builder → download |
| `tvbo-run-in-python.mp4` | `…/specs/demo-python.spec.ts` | Run the spec: brain-surface connectome + region timeseries |
| `tvbo-specify-a-model.mp4` | `…/specs/demo-model.spec.ts` | Specify a `Dynamics` (Lorenz) → run → attractor |
| `tvbo-ext-ontology-simulation.mp4` | `code/vid-tvb-ext-ontology-simulation.sh` (+ `.js`) | JupyterLab `tvb-ext-ontology`: clinical KG → add model → run sim |

All four target the same tvbo ontology / engine; only the front-end differs
(Odoo platform vs JupyterLab extension).

## Regenerating

```sh
# Platform screencasts (needs the Odoo dev server up on :8169):
cd tvbo-platform/tests/e2e && npx playwright test -c playwright.demo.config.ts

# JupyterLab tvb-ext-ontology walkthrough (needs jupyterlab + the extension +
# the tvb-ext-ontology node_modules for playwright + ffmpeg):
bash code/vid-tvb-ext-ontology-simulation.sh
```

## Sync

`code/sync-tvbo-videos.sh` is a Quarto **pre-render hook**: it copies the three
platform `.mp4`s from `tvbo-platform/tests/e2e/demo-output/` into
`img/videos/` so the slides always embed the freshest recordings. The
ext-ontology video is produced in this repo, so it is **not** synced — it lives
in `img/videos/` directly.
